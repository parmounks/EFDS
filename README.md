# 🔥 AI-Based Real-Time Forest Fire Detection System

## **Project Overview**
This project is an AI-based system designed for the **early detection of forest fires** using satellite imagery. The system integrates **Google Cloud**, **Flask API**, and ** near real-time notifications** to provide users with instant alerts upon fire detection. The primary goals include scalability, low latency, and interactive user notifications through SMS, email, and UI updates.

## **Project Milestones**

### **Sprint 1: Setting Up Development Environment and Basic Architecture**
- **Tasks**:
  - Set up project environment using HTML-CSS for the frontend and configure Google Colab & Google Earth Engine.
  - Initial backend setup with Flask.
  - Establish basic UI components (e.g., dashboard).
- **Deliverable**: A structured project environment with front-end and API communicating and Google Cloud ready for AI integration.

### **Sprint 2: AI Integration with Google Cloud and Backend Development**
- **Milestone**: AI model integration with backend and API responsiveness.
- **Tasks**:
  - Deploy AI model on Google Cloud and implement image patching.
  - Create API endpoints for real-time fire detection data.
  - Integrate WebSocket to update frontend upon fire detection events.
- **Deliverable**: Backend that communicates with the cloud, fetches fire detection data, and updates the frontend in real time.

### **Sprint 3: Frontend Development and UI/UX Design**
- **Milestone**: Functional UI with real-time data interaction.
- **Tasks**:
  - Design and implement UI for real-time fire status display and AI detection trigger.
  - Integrate an interactive map to show detected fire locations.
  - Develop a notification system for real-time updates.
- **Deliverable**: Interactive frontend showing real-time fire detection results.

### **Sprint 4: Email/SMS Notifications and Automation**
- **Milestone**: Automated email and SMS alerts upon fire detection.
- **Tasks**:
  - Integrate Twilio for SMS notifications.
  - Backend logic to trigger email/SMS alerts in real-time.
- **Deliverable**: Automated real-time notifications for users via email and SMS.

### **Sprint 5: Testing, Deployment, and Final Improvements**
- **Milestone**: Fully tested, deployed, and optimized system.
- **Tasks**:
  - Perform unit and integration testing, covering all edge cases.
  - Deploy frontend and backend on Google Cloud.
  - Optimize performance for real-time data and scalability.
- **Deliverable**: A deployed, scalable system detecting fires and alerting users in real-time.

## **Technologies Used**
- **Frontend**: HTML, CSS
- **Backend**: Flask API, Google Cloud
- **AI Model**: Google Colab, Phyton
- **Notifications**: Twilio (SMS), Email API
- **Data Management**: WebSocket, Axios/HTTP requests
